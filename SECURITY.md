# Security Policy

## Repository Purpose

This is a security engineering portfolio and learning repository. 
No production systems are represented. All configurations are 
deployed in a dedicated lab environment.

## Sensitive Data Policy

- No secrets, keys, connection strings, or credentials are 
  committed to this repository
- All authentication in scripts uses Managed Identities or 
  environment variables — never hardcoded credentials
- Screenshots are reviewed before upload — subscription IDs, 
  tenant IDs, and object IDs are visible only where needed 
  to demonstrate a concept

## Reporting

If you spot sensitive data that should not be public, open 
an issue immediately. It will be removed from history 
within 24 hours.
