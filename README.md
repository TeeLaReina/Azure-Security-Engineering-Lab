# Azure Security Engineering Lab

A hands-on Azure security engineering lab demonstrating practical 
implementation of security controls across identity, network, compute, 
storage, threat detection, and AI security — aligned to the SC-500 
and AZ-500 certification curricula.

## What This Demonstrates

This lab implements a layered security architecture across Microsoft 
Azure and Microsoft Entra ID. Each phase builds on the previous one, 
adding a distinct security layer with documented decisions, 
configurations, and evidence.

## Environment

- Microsoft Azure (subscription)
- Microsoft Entra ID (Wardenix tenant)
- Microsoft Entra ID P2 (identity protection and governance)
- Microsoft Sentinel (SIEM + SOAR)
- Defender for Cloud (CSPM + workload protection)
